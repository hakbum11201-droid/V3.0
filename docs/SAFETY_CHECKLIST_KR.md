# 실거래 전 체크리스트

1. 최소 2~4주 페이퍼 로그 확보
2. 총 거래 수 100회 이상 확보
3. 승률보다 기대값이 양수인지 확인
4. Profit Factor 1.3 이상 여부 확인
5. 최대 낙폭(MDD) 허용 가능 여부 확인
6. 연속 손실 4회 이상 발생 시 전략 중지 기준 확인
7. 수수료/슬리피지 반영 여부 확인
8. 호가 잔량/부분체결/주문 실패 모델 추가
9. API Key는 환경변수 또는 별도 보안 저장소 사용
10. 주문 테스트 API부터 확인
11. 소액 실거래는 별도 live adapter 코드 리뷰 후 진행
