# coinB PRO V3.0 문서 체계 안내

본 프로젝트의 원활한 운영과 연구를 위해 각 문서의 우선순위와 용도를 다음과 같이 정의합니다.

| 우선순위 | 문서 경로 | 용도 | 확인 시점 |
| :--- | :--- | :--- | :--- |
| **1순위** | `docs/V3_LIVE_TRADING_MASTER_PLAN_KR.md` | 최상위 목표, 전략 철학, 실거래 전환 기준 | 프로젝트 방향성 재확인 시 |
| **2순위** | `docs/DevState.md` | 현재 개발 진척도 및 다음 작업 목록 | 매 작업 시작 전 |
| **3순위** | `docs/CURRENT_RESEARCH_STATE_KR.md` | 전략(Reversal Edge 등) 연구 현황 및 인계 사항 | 분석 및 전략 수정 전 |
| **4순위** | `docs/V3_ROADMAP_KR.md` | 장기 개발 순서 및 마일스톤 | 향후 계획 수립 시 |
| **5순위** | `docs/V3_UI_DDM_ROADMAP_KR.md` | UI 및 DDM(Drawdown Defense) 세부 계획 | 관제 시스템 관련 작업 시 |
| **6순위** | `docs/SECURITY_KEY_POLICY_KR.md` | API Key 및 보안 관리 기준 | 보안 관련 설정 변경 시 |
| **7순위** | `docs/SAFETY_CHECKLIST_KR.md` | 실거래 전환 전 최종 점검표 | 실거래 모드 진입 직전 |

> [!IMPORTANT]

> 문서 간 내용이 충돌할 경우 상위 우선순위 문서의 내용을 최종 기준으로 삼습니다.
